## 💼 the pitch

I run my career like a trading floor — high conviction, fast execution, and a healthy respect for the fact that everything can go red in one bad quarter. By day I think in margins and market fit. By 2 AM I'm three tabs deep in Stack Overflow with the lights off, somehow still convinced this is the same skillset.

Wall Street taught me to read a room before I speak. Writing code alone at night taught me nobody's coming to save your pull request but you. Somewhere between the two, I ended up building infrastructure that has to be trusted with things that actually matter — money, records, audit trails. Turns out "don't lose the client's money" and "don't lose the client's data" require the exact same paranoia.
